# 🌿 Smart Plant Doctor

### Deep Learning-Based Plant Disease Detection & Plant Health Assistant

Smart Plant Doctor is a Deep Learning-based web application that detects plant diseases from leaf images and provides useful plant health information.

The application uses a trained Deep Learning model to classify plant leaf images into supported disease categories and displays the predicted disease, confidence score, disease information, treatment guidance, prevention tips, plant care recommendations, and prediction history.

---

## 🚀 Project Overview

Plant diseases can negatively affect crop health and productivity. Early identification of symptoms can help in taking suitable preventive and treatment measures.

Smart Plant Doctor provides a simple image-based solution where users can upload a plant leaf image and receive an AI-based disease prediction.
